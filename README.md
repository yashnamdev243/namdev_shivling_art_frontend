# React Project Setup

## Install
npm install

## Tailwind
npx tailwindcss init -p (already configured)

## Run
npm run dev

Included:
- React + Vite
- Tailwind CSS
- React Router
- Axios
- Ant Design
- React Icons
- Framer Motion
- Swiper
- Dayjs
- React Helmet Async

Folder structure:
src/
  assets/
  components/
  hooks/
  layouts/
  pages/
  routes/
  services/
  utils/
